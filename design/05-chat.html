Meto · Chat

Design draft 1 · Chats list, Chat, New chat, Call log · Rose + Gold theme

Kaise kaam karega

  • Real-time: Socket.io se message turant aata hai. typing…, online/offline, aur ticks: ✓ = bheja, ✓✓ grey = pahuncha, ✓✓ blue = padh liya.
  • Chats list: upar Meto Team (official notice, pinned). Filters: All · Unread · Calls. Unread count pink badge me, Chats tab pe bhi total count.
  • Chat: text, emoji, photo bhejna, gift bhejna (Wallet phase me coins kategi), upar se seedha Video Call. ⋯ menu me: View profile, Mute, Block, Report, Clear chat.
  • Naya chat: user ki photo + 3 quick "hello" buttons, aur safety tip (paise/OTP kabhi mat bhejo). Ye scam rokne ke liye zaroori hai.
  • Calls tab: outgoing ↗ / incoming ↙ / missed (laal), duration, kitne coins kate, aur dobara call button. (Video call phase ke baad data aayega.)
  • Safety: blocked user message nahi bhej sakta, links/phone numbers pe warning, spam rate limit, report karne pe chat admin ko jaati hai.
